# Video Sitemap Generator — DA App

A Document Authoring (DA) app that generates `video-sitemap.xml` and publishes it via the DA Admin API — **no git commits required**.

## Overview

Previously `video-sitemap.xml` was generated by a GitHub Actions workflow (`video-sitemap.yaml`) and committed to the repository. This DA app replaces that approach entirely:

| | Old approach | New approach |
|---|---|---|
| Trigger | GitHub Actions (daily cron / manual) | DA App (manual, on-demand) |
| Output | Committed to `main` branch | Stored in DA, published via DA Admin API |
| Git commits | Yes — a bot commit per run | **None** |
| Auth | GitHub bot token | IMS/DA user session |

## How it works

1. Reads `/video-index.json` from the configured live host.
2. Filters pages that have a `videourl` column (populated by the Video Feature block).
3. Generates a [Google Video Sitemap](https://developers.google.com/search/docs/crawling-indexing/sitemaps/video-sitemaps) (XML):
   - YouTube/Vimeo URLs → `<video:player_loc>`
   - Direct video file URLs → `<video:content_loc>`
4. Writes the XML to DA via `PUT https://admin.da.live/source/{org}/{repo}/video-sitemap.xml`.
5. Publishes the file via `POST https://admin.da.live/publish/{org}/{repo}/video-sitemap.xml`, making it available at `https://{liveHost}/video-sitemap.xml`.

## Usage in DA

Open the app in DA:

```
https://da.live/app/{org}/{repo}/tools/apps/video-sitemap/video-sitemap
```

The app auto-detects `org` and `repo` from the DA context. The live host defaults to `https://main--{repo}--{org}.aem.live` and can be overridden in the UI.

Click **⟳ Generate & Publish Sitemap** to run the generation and publish cycle.

## Disabling the GitHub Actions workflow

Once this DA app is in production, the old GitHub Actions workflow at
`.github/workflows/video-sitemap.yaml` can be disabled (or deleted) so it no
longer commits `video-sitemap.xml` to the repository.

The `video-sitemap.xml` file in the repository root can also be removed once
the DA-published version is confirmed to be serving correctly.
